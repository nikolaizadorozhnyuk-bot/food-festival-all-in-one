# 🍏 Food Festival ERP System

Інтелектуальна система управління замовленнями та аналітики для компанії **Food Festival**.

## 🚀 Основні функції

* 🛒 **Каталог товарів:** Відображення актуальних залишків та персональних цін для кожного клієнта.
* 📦 **Управління замовленнями:** Оформлення замовлень із автоматичним розрахунком часу доставки (поріг 11:00).
* 📜 **Історія замовлень:** Перегляд клієнтами своїх попередніх покупок та їх статусів.
* 📊 **Адмін-панель:** Аналітика продажів, топ-товари та активність клієнтів для директора.
* 🔔 **Автоматизація:** Щоденні нагадування клієнтам та щотижневі звіти для бізнесу в Telegram.

## 🛠 Технологічний стек

* **Frontend/Backend:** Python & Streamlit
* **База даних:** Google Sheets API (опубліковані CSV)
* **Сповіщення:** Telegram Bot API
* **Автоматизація:** GitHub Actions (Cron jobs)

## 📁 Структура проекту

* `app.py` — головний веб-додаток (інтерфейс та логіка системи).
* `scheduler.py` — скрипт для автоматичних нагадувань клієнтам та формування звітів.
* `requirements.txt` — список Python-бібліотек для роботи системи.
* `.github/workflows/` — налаштування розкладу запусків бота (GitHub Actions).

## ⚙️ Налаштування та запуск

1. Підключити Google Таблиці через посилання формату CSV.
2. Вказати `TELEGRAM_TOKEN` та `CHAT_ID` у коді (або безпечно через GitHub Secrets).
3. Розгорнути додаток через **Streamlit Cloud**.
