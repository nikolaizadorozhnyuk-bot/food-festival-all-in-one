# 🍏 Food Festival ERP System

Інтелектуальна система управління замовленнями та аналітики для компанії **Food Festival**.

## 🚀 Основні функції
* **🛒 Каталог товарів:** Відображення актуальних залишків та персональних цін для кожного клієнта.
* **📦 Управління замовленнями:** Оформлення замовлень із автоматичним розрахунком часу доставки (поріг 11:00).
* **📜 Історія замовлень:** Перегляд клієнтами своїх попередніх покупок та їх статусів.
* **📊 Адмін-панель:** Аналітика продажів, топ-товари та активність клієнтів для директора.
* **🔔 Автоматизація:** Щоденні та щотижневі звіти менеджерам і директору в Telegram.

## 🛠 Технологічний стек
* **Frontend/Backend:** Python & [Streamlit](https://streamlit.io/)
* **База даних:** Google Sheets API (CSV)
* **Сповіщення:** Telegram Bot API
* **Автоматизація:** GitHub Actions (Cron jobs)

## 📁 Структура проекту
* `app.py` — головний додаток (інтерфейс та логіка).
* `scheduler.py` — скрипт для автоматичних нагадувань та звітів.
* `requirements.txt` — список бібліотек для роботи системи.
* `.github/workflows/` — налаштування розкладу запусків бота.

## ⚙️ Налаштування
1. Підключити Google Таблиці через посилання CSV.
2. Вказати `TELEGRAM_TOKEN` та `CHAT_ID` у коді (або в Secrets).
3. Розгорнути через Streamlit Cloud.
